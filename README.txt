MY TRAVEL JOURNAL - HTML/CSS ASSIGNMENT

Folder structure:
- index.html
- destinations.html
- gallery.html
- css/style.css

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html.
4. Right-click inside the editor and choose "Open with Live Server" (if Live Server is installed), or double-click index.html to open it in a browser.
5. Use the navigation links to open the other two pages.

IMPORTANT:
- The images are loaded from Unsplash using internet URLs. You need an internet connection to display them.
- Replace the sample images with your own photos if your instructor requires personal images.
- The pages and CSS are written in English to suit an HTML/CSS website assignment.
